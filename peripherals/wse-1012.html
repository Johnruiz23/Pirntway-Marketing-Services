COATING MACHINE

WSE-1012

Automatic Screen Coating Machine

Winon Industrial Co., Ltd. — Dongguan, China

The Winon WSE-1012 is an automatic screen coating machine that applies photosensitive emulsion uniformly across large printing screens. Stepless coating speed control allows the emulsion layer thickness to be tuned for different mesh counts and job requirements.

Technical Parameters

Mechanical ModelWSE-1012
Power Specifications220V 50 Hz
Electric Power1.3 kW
Air Supply0.6 ~ 0.8 MPa
Max. Outer Size1000 x 1200 mm
Max. Coating Stroke1000 x 1100 mm
Coating Speed0 ~ 1200 mm/s
Dimensions2080 x 580 x 2080 mm
Weight400 kg
Noise<= 75 dB

KEY FEATURES

Technical Features

Even Emulsion Coating

Applies a uniform photosensitive emulsion layer across the full screen surface.

Large Frame Capacity

Handles frames up to 1000 x 1200 mm outer size for large-format screens.

Stepless Speed Control

Coating speed from 0 to 1200 mm/s lets you adjust layer thickness to suit mesh and job type.
